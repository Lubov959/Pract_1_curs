# Задание 1.3 ИСР 
## Часть 1
### 1. Структура программы

Сайт кафедры информационных технологий и электронного обучения 
РГПУ им. А. И. Герцена представляет собой веб-приложение, 
реализованное на основе CMS Grav и развертываемое в контейнеризированной среде.

В состав программы входят следующие основные компоненты:

- CMS Grav;
- веб-сервер Nginx;
- PHP-интерпретатор;
- Docker-контейнер;
- система автоматической сборки и публикации GitLab CI/CD;
- Kubernetes-инфраструктура.


## 1.1 Структура серверной части

Серверная часть сайта функционирует внутри Docker-контейнера, 
созданного на основе образа: 
_dmitriizolotov2/grav_


В контейнере размещаются:

- CMS Grav;
- веб-сервер Nginx;
- PHP-интерпретатор;
- пользовательские файлы сайта.

Файлы сайта копируются в каталог:
_/usr/share/nginx/html_


Основной контент сайта расположен в директории:
_grav/user/_


В каталоге находятся страницы сайта, шаблоны оформления, плагины
и конфигурационные файлы.



## 1.2 Система автоматической сборки и публикации

Автоматическая сборка и публикация сайта выполняется средствами 
GitLab CI/CD.

Конвейер включает следующие этапы:

- _build_ — сборка Docker-контейнера;
- _publish_ — публикация приложения в Kubernetes;
- _cleanup_ — удаление устаревших Docker-образов.

После сборки контейнер публикуется в GitLab Container Registry 
и используется Kubernetes для запуска приложения.



## 1.3 Kubernetes-инфраструктура

Развертывание сайта выполняется c помощью Kubernetes.

В Kubernetes используются следующие компоненты:

- _Deployment_ — запуск контейнера приложения;
- _Service_ — обеспечение сетевого доступа к приложению;
- _Ingress_ — обработка HTTP-запросов пользователей.

Доступ к сайту осуществляется через домен:
_ict.herzen.spb.ru_


---

## 2. Связи между составными частями программы

Взаимодействие компонентов осуществляется следующим образом:

1. Пользователь открывает сайт в браузере.
2. HTTP-запрос поступает в Ingress Kubernetes.
3. Ingress передает запрос приложению.
4. Веб-сервер Nginx принимает запрос и передает его CMS Grav.
5. CMS Grav загружает содержимое страниц и шаблоны оформления.
6. PHP выполняет обработку данных и формирует HTML-страницу.
7. Сформированная страница передается пользователю.

---

## 3. Связи с другими программами

Сайт взаимодействует со следующими внешними программными средствами:

- GitLab CI/CD;
- GitLab Container Registry;
- Kubernetes;
- Docker;
- OAuth2;
- Nginx Ingress Controller.


# Часть 2 
## Используемое программное обеспечение и технологии

| Программное обеспечение / технология | Назначение |
|---|---|
| CMS Grav | Используется в качестве системы управления содержимым сайта. Обеспечивает хранение контента, маршрутизацию страниц, подключение шаблонов и генерацию HTML-страниц. |
| PHP | Используется для выполнения серверной логики CMS Grav, обработки пользовательских запросов и генерации динамического содержимого. |
| Nginx | Используется как веб-сервер для обработки HTTP-запросов и выдачи содержимого сайта пользователям. |
| Docker | Используется для контейнеризации веб-приложения и создания изолированной среды выполнения сайта. |
| Dockerfile | Используется для автоматической сборки Docker-контейнера с веб-приложением. |
| GitLab CI/CD | Используется для автоматической сборки, публикации и обновления приложения. |
| Kaniko | Используется в CI/CD-конвейере для сборки Docker-образов без использования Docker Daemon. |
| GitLab Container Registry | Используется для хранения Docker-образов приложения и управления версиями контейнеров. |
| Kubernetes | Используется для размещения и управления контейнерами веб-приложения. |
| Kubernetes Deployment | Используется для запуска и обновления контейнеров приложения в Kubernetes-кластере. |
| Kubernetes Service | Используется для организации сетевого доступа к контейнеру приложения внутри Kubernetes-кластера. |
| Kubernetes Ingress | Используется для обработки внешних HTTP-запросов и маршрутизации трафика к веб-приложению. |
| OAuth2 | Используется для авторизации пользователей и обработки аутентификации. |
| Markdown | Используется для хранения текстового содержимого страниц сайта. |
| YAML | Используется для хранения конфигурационных файлов. |
| Twig | Используется как шаблонизатор для формирования HTML-страниц сайта. |
| Python | Используется для выполнения служебных скриптов автоматизации и очистки Docker Registry. |
| gricleaner.py | Используется для автоматического удаления устаревших Docker-образов из GitLab Container Registry. |
| HTML | Используется для формирования структуры веб-страниц сайта. |
| CSS | Используется для оформления и стилизации пользовательского интерфейса сайта. |
| JavaScript | Используется для реализации клиентской логики и интерактивных элементов интерфейса. |
